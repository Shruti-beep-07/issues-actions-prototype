# ConfluxaaOne Landing Page Prototype

## Run in VS Code

1. Open this folder in VS Code.
2. Install the **Live Server** extension if you have it.
3. Right-click `index.html` -> **Open with Live Server**.
4. Edit `styles.css` for visual changes and `index.html` for content.
5. The latest generated visual is stored at `assets/confluxaaone-reference.png` as a design reference.

## Important
The page is intentionally built with plain HTML/CSS/JS so you can prototype quickly without React or npm.
